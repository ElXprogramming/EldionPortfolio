# Contributing to EldionPortfolio

Thank you for your interest in contributing to **EldionPortfolio**!

## Development Setup

```bash
git clone https://github.com/<your-username>/EldionPortfolio.git
cd EldionPortfolio
npm install
cp .env.example .env.local
npm run dev
```

## Verification Checks

Before opening a pull request, verify:

```bash
npm run lint
npm test
npm run build
```

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
